# 开口 Fluent

[打开统一学习网址](https://codeandylau.github.io/fluent-speaking/)

12 周 72 个学习日、入门诊断、24 章双语有声书，以及 7000 个可检索和自行练习的词条。

词汇新版包含 24 个生活场景、73 个词义／搭配学习点和 Andrew 音频，支持听辨、渐退提示、主动提取、换情境开口和间隔复习。场景覆盖原词库中的 63 个不同单词；7000 词的逐义场景教学尚未全部完成。1357 个词关联课程／故事双语原句，其余可建立个人记忆线索。

课程、故事、表达本及词汇进度保存在当前浏览器，可从「学习记录备份」导出和恢复。录音不上传。
