# 开口 Fluent

公开英语听说学习站，包含 12 周 72 个学习日、24 章完整有声书、3500 个基础词和 3500 个进阶词，以及 320 条日常短语。

发布地址：https://codeandylau.github.io/fluent-speaking/

本仓库只保存学习站静态发布资源。学习记录保存在访客浏览器中；录音不会上传。词汇释义来源和 MIT 许可见 `vocabulary/LICENSE` 及学习页面说明。

源码维护位置：本机 `fluent-preview`。发布时复制其 `dist/`，保留 `.nojekyll`，由 GitHub Pages 从 `main` 分支根目录发布。
