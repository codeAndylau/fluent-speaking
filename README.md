# 开口 Fluent · 英语听说与词汇

静态英语学习平台：12 周、72 个学习日与入门诊断；24 章完整有声书；按实际字幕词形频次排序的7000个词条，分为前3500与后3500两个学习段。每周课程包含 4 节主题／挑战课、1 节跨课复习和 1 节新任务周测。

## 打开

在本目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

浏览器打开 http://127.0.0.1:8765/ 。日常使用不需安装依赖。

## 学习流程

1. 入门诊断：先听后答，再看文字重答，最后实际开口并自评。首次听力与阅读辅助成绩分别保留；重复作答有练习效应，不据此判定 CEFR。
2. 每课约 30 分钟：听与理解约 7 分钟，三轮输出及同伴任务约 15 分钟，回听、自评与复习约 8 分钟。这是主动练习建议，不是录播课时。
3. 周测使用新对话，首次答题前隐藏文本、语块、角色提示及可能泄露答案的具体目标。理解题错误可继续学习，不要求反复猜到全对。
4. 第 4、8、12 周有阶段记录，区分首次理解题、自评与同伴问答。独自模拟不等于验证真实互动能力。
5. 表达本先显示使用场景，主动回忆后再看英文。成功回忆使用 1、3、7、14、30 天间隔，需提示时回到次日。
6. 每周至少一次真实同伴信息差问答。角色 B 信息默认折叠，请同伴单独看；没有同伴时如实记录独练。

## 已提供

- 72 个完整学习日＋1 次诊断；219 道理解题与解析；216 个课程表达条目。
- 每课独立 MP3、句级播放时间轴、中英文本、三轮输出、发音重点、纠错、迁移与自评。
- Andrew 美式合成语音为主，第 9–12 周周测使用 Ava。共 73 段，示范对话约 28.6 分钟，需要反复听说与主动输出。
- 浏览器本地保存课程进度、首次／最近理解题、自评、同伴状态与表达复习安排；兼容原首课收藏和完成记录。
- 录音、回听和下载界面；录音仅在当前页面内存，离开步骤即释放，不上传。

## 内容维护与验证

源内容在 `content/`，发布资源在 `dist/`。修改 JSON 后运行：

```sh
node scripts/build-course.mjs --verify-audio
node --test tests/*.test.mjs
node --check dist/app.js
```

音频生成脚本 `scripts/generate-course-audio.py` 依赖 `edge-tts==7.3.1`、ffmpeg、ffprobe。只发送原创英文示范文本。按内容摘要复用资源；更改对话后重新生成，再执行音频构建校验。

## 使用边界

没有 AI 对话、自动发音评分或服务端账号。浏览器清除站点数据会丢失学习记录；可在「学习记录备份」导出 JSON 并在另一设备恢复。录音需在离开步骤前下载。学习记录按浏览器和网站地址分别保存，本地预览记录不会自动出现在公网网站。资源与流程检查通过不等于已经验证学习效果；仍需真实学员试学、人工听审和真实设备麦克风测试。完整证据见 `VERIFICATION.md`。

## 故事听说与词汇

1. 故事使用本项目《A Place at the Table》r2 版全部 24 章，含原音频、2761 句中英文本、120 个表达、72 道理解问答、72 轮角色任务，以及每章发音、语法、迁移和复述。章音频支持连续播放、选句与循环，听读和口语练习分开记录。
2. 7000 个词条均有一个选定义项的原创场景单元：中英释义、自然搭配、双语例句和换情境表达任务。前3500/后3500仅是学习分段，不是CEFR等级。默认按SUBTLEX-US真实词形出现次数降序，其次样本覆盖数，同分按字母序；没有人工课程权重。
3. 每天词汇建议10–15分钟：先复习到期项，再理解少量新情景，听句子，隐去答案提取，最后换情境开口。已认识的词可直接做提取检查。正常/慢速听句、可选录音、自评和跨日提取分开记录。
4. 20个频率学习组每组350词，保留原24个生活场景及历史记录。7000句原创示范使用Andrew合成语音，按100句组成70个带内容摘要的音频分包；按句起止范围播放，句间留有间隔。单词及搭配的单独朗读使用设备系统语音。
5. 词典数据来自 [ECDICT](https://github.com/skywind3000/ECDICT)，保留MIT许可；逐词公开出现次数、每百万次数、样本覆盖、筛选规则和原始文件摘要。数据来自[根特大学SUBTLEX-US](https://www.ugent.be/pp/experimentele-psychologie/en/research/documents/subtlexus)，并非2026实时语料。字幕频次有语域偏差，词形次数不等于某个义项的次数；7000中包含较低频拓展词，不能称为人人每天都要用的7000词。
6. 320条日常短语可收藏到统一表达本。1307个词另有实际课程/故事用例及来源跳转，可能不同义项的原文用例单独折叠。全部7000词条的教学覆盖指每词一个义项，不代表穷尽所有多义用法。

## 学习地图与设置

从页首「使用攻略」进入可视化学习地图、九个页面的用途、每天10–15分钟词汇/约30分钟口语路线及FAQ。

从页首或页脚「设置」进入：

1. 主题模式：浅色、深色或跟随系统，系统模式响应设备明暗变化。
2. 界面皮肤：森林绿、海洋蓝、暖沙色。
3. 语言：中文/English，覆盖界面、课程说明、故事及词汇学习内容。学习者自己输入的笔记不自动翻译。切换语言会重新加载，已保存记录保留；词汇场景当前一轮的位置、输入和提示在当前标签页暂存24小时，可点“继续未完成的练习”恢复。其他未提交输入和临时录音需先保存。
4. 学习与记录：学习攻略、记录备份、词库来源、练习方法依据。偏好按浏览器保存，当前没有账号或自动跨设备同步。

## 全量词汇构建

原始频率审计与筛选脚本为 `scripts/audit-frequency.py`，来源哈希记录于 `dist/vocabulary/rankings.json`。逐词源文件位于 `content/curriculum-source/units-*.jsonl`。正式构建遇到缺词、重复词或必填字段错误会退出，不发布部分覆盖：

```sh
python3 scripts/build-curriculum.py
python3 scripts/build-curriculum-audio.py
node --test tests/*.test.mjs
node scripts/audit-rendered-language.mjs
```

音频脚本需要安装edge-tts、ffmpeg及ffprobe，依赖配置与既有课程语音脚本一致；音频生成后不要单独重建curriculum，否则需要再次运行音频脚本恢复经校验的片段引用。`--prepare`可预生成已完整的分组，仅缓存音频，不生成正式课程或发布清单。
